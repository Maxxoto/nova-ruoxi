## 🗺️ Feature Roadmap

Nova / 若曦 is evolving steadily toward becoming a deeply personalized, agentic second brain. Below is a categorized roadmap outlining current progress and future features.

---

### ✅ Phase 1: Core Foundation (In Progress)

✔️ Conversational AI with dynamic role prompting  
✔️ Task-specific model routing via OpenRouter and Groq  
✔️ Bilingual support (English + 中文)  
✔️ Basic knowledge retrieval and summarization  
✔️ Embedding storage using ChromaDB  
✔️ Modular persona definition (Nova / 若曦)  
✔️ Optional FastAPI backend for orchestration  

---

### 🔜 Phase 2: Personalization & Agentic Behavior

🧠 **Memory & Cognitive Profile (MCP)**  
- Identity, goals, preferences tracking  
- Contextual memory recall and adaptive prompts  
- JSON + embedding-based storage

🎭 **Persona Switching System**  
- Customizable tones: teacher, friend, critic, etc.  
- Role-based behavior templates

📥 **Inbox Summarizer Agent**  
- Summarize emails or messages into concise digests  

📊 **Data Analyst Agent**  
- Interpret CSVs and spreadsheets  
- Generate visualizations and insights using pandas + plotly  

⏱️ **Task Manager Integration**  
- Calendar sync (Google Calendar or iCal)  
- Task tracking with priority and context

---

### 🧪 Phase 3: Multimodal & Voice Interactions

🎙️ **Voice Mode (TTS + STT)**  
- Personalized voice generation via frontier TTS models  
- Speaker diarization support for multi-user sessions  

🗣️ **Background Speech-to-Text**  
- Passive listening mode for pair programming or meetings  

🖼️ **Vision Capabilities** *(Planned)*  
- OCR + image-to-text for document or chart explanation  
- Visual input integration for multimodal tasks  

🧾 **Visual Knowledge Canvas** *(Planned)*  
- Mind maps, timelines, concept graphs from memory  

---

### 💼 Phase 4: Specialized Agents / Domains

🌍 **Travel Planner Agent**  
- Generate itineraries and book travel via API integrations  

💸 **Financial Advisor Agent**  
- Budgeting, expense tracking, and investment suggestions  
- Finetuned open-source finance models or RAG-based tooling  

🔌 **Tool Use & Plugin API** *(Planned)*  
- Let Nova interact with external APIs, shell commands, or apps via agent tools  

🔐 **Encrypted Knowledge Vaults** *(Planned)*  
- Private data stores bound to user profiles with optional auth  

---

## 📌 Long-Term Vision

Nova will evolve into a modular, multimodal cognitive framework that mirrors your thinking, adapts to your goals, and acts as a lifelong learning companion — across domains, devices, and languages.
